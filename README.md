# KINGMAN Adventure\nเกมวิ่งผจญภัย React + Vite\n\n1. `npm install`\n2. `npm run dev`\n3. Deploy ไป Vercel ด้วย Build Command `npm run build` และ Output Directory `dist`\n\nเชื่อม Supabase: รัน `supabase.sql` แล้วตั้ง `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` ใน Vercel (ใช้ Publishable/anon key เท่านั้น)\n\nใส่ภาพ KINGMAN PNG พื้นหลังโปร่งใสไว้ที่ `public/kingman.png` เพื่อแทนตัวละคร emoji ในเวอร์ชันถัดไป
